Metric glossary — click to collapse

Match categories

  • Correct (COR) — predicted entity exactly matches a gold entity (same span and type).
  • Partial (PAR) — predicted span overlaps a gold span but isn't identical (boundaries differ).
  • Spurious (SPU) — model predicted an entity where the gold has none (false positive).
  • Missed (MIS) — a gold entity that the model failed to predict (false negative).

Higher COR is better. Higher SPU / MIS is worse.

Evaluation mode

  • Strict (S) — both the entity boundary and its type must match exactly. This dashboard focuses on the strict metrics only.

Reported as S-P = Strict Precision, S-R = Strict Recall, S-F1 = Strict F1 (harmonic mean).
